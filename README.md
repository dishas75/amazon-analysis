# 📊 Amazon Sales Performance Dashboard

An interactive Excel dashboard built as part of a **One-Day Dashboard Challenge** using a transactional Amazon sales dataset containing approximately **100,000 records**.

The goal of this project was to design a clean, business-focused, and presentation-ready dashboard within a limited time frame using only Microsoft Excel.

---

# 🚀 Project Overview

This dashboard provides insights into:

* Overall business performance
* Revenue trends over time
* Product category performance
* Order fulfillment status
* Customer payment preferences

The dashboard was designed to be:

* Interactive
* Simple to understand
* Visually clean
* Suitable for presentations and portfolio use

---

# 📌 Features

## KPI Cards

* Total Revenue
* Total Orders
* Quantity Sold
* Average Order Value (AOV)
* Delivered Orders %

## Visualizations

* Monthly Sales Trend
* Sales by Category
* Order Status Distribution
* Payment Method Analysis
* Yearly Monthly Sales Matrix (Heatmap)

## Interactivity

* Slicers for:

  * Year
  * Category
  * Order Status
  * Country

# 📈 Key Insights

* Electronics generated the highest revenue among all categories.
* Delivered orders accounted for the majority of total orders.
* Credit Card and Debit Card were among the most preferred payment methods.
* Monthly sales remained relatively stable with slight fluctuations across months.

This project was completed as a **One-Day Excel Dashboard Challenge**, focused on building a professional dashboard under time constraints while maintaining clarity, usability, and visual consistency.

A major focus during development was not just analysis, but also:

* Dashboard aesthetics
